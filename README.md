# Hotel Natraj & Resort

Website for Hotel Natraj & Resort, Delwad, Gandhinagar–Mahudi Highway Road, Gujarat.

Plain HTML, CSS and JavaScript, with no build step. Open `index.html` in a browser, or serve the folder with GitHub Pages.

- `index.html`: the page
- `css/style.css`: styles. The colours come from ajrakh block prints (indigo, madder red, turmeric).
- `js/main.js`: cottage tabs, gallery, lightbox and the list of nearby places

Photos load from natrajhotel.co.in. To host them yourself, copy them into an `images/` folder and update the URLs.
